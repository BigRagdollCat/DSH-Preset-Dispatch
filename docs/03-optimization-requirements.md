# Agent 管理：A/B/D 全量优化需求清单

状态：用户已确认全量优化范围；本文为实施与验收依据，不表示功能已完成。

适用插件：`@local/dsh-preset-dispatch`。基线版本：v0.5.0，上一轮验收为 121 项测试、33 个模块语法检查、19 项冻结哈希检查通过；这些数字仅是历史基线，不是本轮功能验收证据。

配套文档：[工作清单](<04-optimization-worklist.md>)。
历史设计：[初始需求](<01-requirements.md>)、[初始开发方案](<02-development-plan.md>)。历史文档中的两页布局、递增 Host 入口等描述仅代表当时方案；冲突时以本文及最新用户要求为准。

## 1. 目标与范围

完整落实 A（可靠性）、B（功能扩展）、D（工程治理）三类优化，形成具备策略生命周期、故障恢复、历史持久化和可重复发布验证能力的 Agent 管理插件。分批交付只控制依赖，不缩减范围。

保留以下约束：

- 卡片点击打开一个独立设置弹窗，合并角色设置与派遣设置；不改成页面内折叠编辑。
- 保持 DSH 原生视觉风格，优先复用已验证控件与主题令牌。
- 只有本插件管理的预设可操作；原生及其他插件预设完全只读，前后端一致。
- 不擅自更改七个现有角色的职责、工具权限、默认模型、思考强度及授权池。
- 模型目录可见性不等于授权；缓存、复制、恢复和迁移不得隐式扩大权限。
- 不做过期草稿自动合并，不为形式增加 lint/构建依赖。存储方案优先评估 DSH 原生能力，不预设必须引入依赖。
- 全量优化实施授权不等同于无需确认即可重启、删除历史数据或重置用户配置；这些操作遵守当时权限与确认边界。

## 2. 已完成基线与事实修正

| 项目 | 基线状态 | 本轮剩余工作 |
|---|---|---|
| A1 生成器旧入口 | 已改为稳定入口，并要求 `--force` | 补执行行为测试，证明无参数不写文件 |
| D 稳定入口 | 已统一正式入口，删除九个 manager 历史入口 | 治理其他兼容 shim，补引用与升级验证 |
| D 失效 profile 配置 | 四条明确被 Loader 跳过的配置块已备份清理 | 发布时回归检查，不重复清理 |
| D 发布与检查 | 已有清单断言、语法/哈希检查；实际打包曾验证 | 固化实际打包门禁，完成重启与回退验证 |
| UI 主流程 | 用户截图确认卡片与合并弹窗 | 新增交互仍须单独验收 |

事实边界：

1. 正常联合新建成功会写入新策略，不能称为“同 ID 重建必然继承旧策略”。风险存在于定义落盘、策略失败等中间状态，以及绕开联合保存的旧接口。
2. 当前派遣历史在 Host 内存中；普通浏览器刷新不等于清空，插件实例重建或进程重启才会丢失。
3. 预校验及进程内串行队列不是跨存储事务，不能承诺消除所有部分失败。
4. 一键重试必须以去重、实际状态核对和并发冲突处理为基础，不能盲目重放请求。
5. 当前已加载稳定入口不等于完整 DSH 重启验收通过。

## 3. 共用基础需求：保存与权限边界

| ID | 需求 | 验收标准 |
|---|---|---|
| F01 | 所有写入入口统一服务端所有权规则；旧接口停用或委托统一逻辑 | 外部预设经单条、全量、旧接口及全局设置均不能被新增/修改/删除策略；拒绝不产生副作用 |
| F02 | 校验定义、策略、动作和目标 ID 的对应关系 | 拒绝目标错配、非法动作组合及绕过生命周期的请求 |
| F03 | 写入前完整校验定义、策略、模型/强度和全部相关修订号；授权池修订号必填 | 可预先发现的错误或过期请求零写入；写入边界仍复核并发变化 |
| F04 | 保存操作有稳定标识及可辨认的步骤状态 | 区分校验拒绝、分项成功、失败、结果未知；同操作不会重复创建或重复执行已完成步骤 |
| F05 | 全局设置修改与单预设修改明确分离 | 修改深度不无故重写其他策略；收紧授权后的旧策略可读取并显示失效状态，不阻止无关设置修改 |

## 4. A 类：可靠性

| ID | 需求 | 验收标准 |
|---|---|---|
| A01 | 生成器与正式稳定入口一致，重置必须显式确认 | 在隔离夹具中不传 `--force` 时非零退出、目标字节不变；带参数只操作夹具，生成正确入口 |
| A02 | 删除采用失败安全的策略生命周期 | 删除前停用派遣，再删除定义并清理关联策略；后续失败不自动恢复授权，界面如实显示可恢复状态 |
| A03 | 同 ID 重建视为新预设，不默认继承历史授权 | 已有遗留策略被识别；显式清理或确认迁移后才能继续；任一部分失败都不能使新定义获得未确认的旧授权 |
| A04 | 复制拥有独立身份和策略确认 | 目标 ID 可编辑且唯一；不得意外绑定目标 ID 的遗留策略；连续复制可成功 |
| A05 | 派遣真正启动前复核当前权限 | 复核派遣开关、模型/强度范围、锁定设置、Host 授权与相关开关；准备期间变化时明确拒绝，不静默换模型 |
| A06 | 异步创建、删除、撤权协调一致 | 可控时序测试覆盖启动前及创建期间变化；拒绝时释放资源并记录原因。明确启动判定时点及已运行任务语义，不擅自终止既有任务 |

## 5. B 类：功能扩展

### B1 派遣记录持久化

| ID | 需求 | 验收标准 |
|---|---|---|
| H01 | 持久保存必要运行元数据 | 保存唯一运行 ID、预设、模型、时间、状态及子会话关联；刷新、实例重建及进程重启后可查询 |
| H02 | 隐私最小化 | 默认不保存任务正文、回答和思考内容；策略快照字段明确审查，不存凭证 |
| H03 | 数据版本、保留和清理 | 记录有 schema 版本；支持升级迁移及容量/期限限制；清空操作需确认，不误删其他 profile 数据 |
| H04 | 重启后的未完成状态处理 | 核对可恢复追踪的运行；无法核对时标记中断或未知，不伪造成功或继续运行 |
| H05 | 查询与存储故障可观测 | 按预设/状态筛选并分页；存储错误可见，按明确降级策略处理，不静默丢记录或无故阻断派遣 |

### B2 模型目录缓存

| ID | 需求 | 验收标准 |
|---|---|---|
| M01 | 缓存目录和能力元数据，合并并发读取 | 相同有效期内重复请求不重复遍历提供方；并发请求共享适当的读取任务 |
| M02 | 有效期、变更失效与手动刷新 | 核实实际可用事件后接入；事件不可用时有有效期兜底；手动刷新可获取最新目录 |
| M03 | 故障隔离及旧结果保护 | 单提供方失败不清空其他结果；旧数据标记；慢请求不覆盖较新结果；超时/取消不污染缓存 |
| M04 | 授权与缓存彻底分离 | 派遣及保存读取当前授权，撤权立即作用于下一次权限检查，不等待目录缓存过期 |

### B3 预设排序

| ID | 需求 | 验收标准 |
|---|---|---|
| O01 | 自有预设可调整顺序 | 开放排序字段或上移/下移；保存并持久化；不要求首版拖拽 |
| O02 | 管理页与原生列表顺序规则一致 | 同排序值有稳定次序，新建/复制默认位置明确，刷新与重启后保持；不修改外部预设的排序配置 |

### B4 部分失败恢复与重试

| ID | 需求 | 验收标准 |
|---|---|---|
| R01 | 保留草稿、操作身份和基线 | 保存失败可恢复；页面刷新后可以恢复安全允许的状态，草稿敏感字段的存储范围和清理策略明确 |
| R02 | 先核对实际状态，再重试未完成步骤 | 已完成部分不重复执行；重复点击、响应丢失或网络重发不重复创建/扩权 |
| R03 | 无冲突一键继续，有冲突显式比较 | 无冲突可继续；冲突显示当前值与草稿差异，用户确认后重新提交，不自动合并覆盖 |
| R04 | 未知结果及全局副作用安全处理 | 未知结果先查询；重试复核当前授权；不得恢复后来已撤销的授权，不盲目回滚其他会话写入 |
| R05 | 弹窗内分项反馈 | 展示已保存、未保存、失败原因及恢复操作，用户不必关闭弹窗寻找错误 |

## 7. D 类：工程治理与发布

| ID | 需求 | 验收标准 |
|---|---|---|
| D01 | 稳定入口及兼容文件有明确生命周期 | 记录引用者及保留/退役决定；禁止重新引入每次递增入口的开发方式；Host 更新说明要求重启 |
| D02 | 实际发布清单自动验证 | 在不污染源码目录的情况下检查实际打包结果，覆盖入口、脚本及必要资源；排除本机迁移资料、备份与秘密 |
| D03 | 统一门禁覆盖新模块和新故障路径 | 语法、哈希、单元/集成、并发/故障恢复和打包门禁均可重复执行；失败返回非零 |
| D04 | 可升级、可回退 | 更新版本与维护文档，保留升级前配置/必要数据备份；验证迁移失败及回退兼容性，不声称自动支持任意降级 |
| D05 | 独立验证与真实重启验收 | 冻结候选后独立审查/验证；在获准的维护窗口重启 DSH，确认预设、授权、排序、历史和原 GUI 正常 |

## 8. 实施前必须明确的设计决策

以下不缩减需求，但不能在契约未核实时写死实现：

1. 操作状态存储方式、幂等键作用域/有效期、同键不同请求的拒绝规则，以及进程退出后的恢复能力。
2. 定义、策略与授权池之间的提交顺序和失败安全状态；不以“事务”称呼非原子实现。
3. 删除/重建的遗留策略迁移交互和并发派遣的启动判定时点。
4. 历史存储 API、隔离范围、保留默认值、迁移与故障降级方式。
5. 草稿恢复是否存于客户端或 Host，权限范围、保留期限及清理方式。
6. 模型目录事件、缓存有效期、超时与旧数据展示规则。
7. 排序字段的原生契约、同值排序与新建/复制定位规则。
8. 完整重启及真实浏览器验收的可用工具和维护窗口。

## 9. 完成定义

所有需求均有对应任务与验证证据；既有角色默认值和外部只读边界无回归；三批全部交付。自动测试、运行集成、视觉/交互、重启与回退分别记录，不相互替代。未通过的门禁或环境限制必须明确列出，不能因已有 121 项测试通过而宣布新增需求完成。
