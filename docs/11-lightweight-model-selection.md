# 轻量任务分级与选模记录

## 范围

本次增加主代理决策提示和可观察记录，不引入自动模型排名、隐藏评分模型、自动升级或失败重试。保留现有各预设 defaultModel/defaultEffort、lockModel、模型白名单、Host 授权池与工具权限。

## 提示词分层

- `routing.js`：常驻短提醒，要求先判断分工收益，再按复杂度、错误代价与能力需求轻量分级。授权开启时 134 个 Unicode 字符，不是 Token 数。
- `core.js` 的 `preset_list.rules.taskAssessment`：低=范围小/证据足/易验证；中=多处修改或少量未知；高=跨模块因果链/关键安全或数据风险/错误代价高。不得另派代理打分，不要求输出评分长文。
- `preset_list.rules.modelChoice`：能力先于分级；只在该角色实际可用的授权模型与档位内选择。目录不是价格表、能力排名或视觉验证。证据不足时保留预设默认，无默认才继承；任务必需能力未证实时暂停该任务，不把默认值当作具备能力的证明。
- 同一批工作复用已读目录；配置变化或被拒时刷新目录，但不能自动改用其他模型绕过拒绝。
- 不改全局 AGENTS.md，也不增加角色特定的长评分表。

## 调用方式

现有调用完全兼容，`selection` 可省略。动态选择应明确给出模型和实际支持的强度；不传模型仍使用现有默认，分级本身不会改变路由。

```json
{
  "preset": "researcher",
  "task": "这里填写有界的检索任务与验收条件",
  "provider": "codex-chatgpt",
  "model": "gpt-6-sol",
  "reasoning_effort": "medium",
  "selection": {
    "difficulty": "low",
    "reason": "范围明确、证据路径已知；缺少其他模型成本证据，保留授权默认"
  }
}
```

以上只是参数格式示例，不代表该模型最便宜。执行前仍应查询实际目录。

`selection` 提供时必须只包含 `difficulty`（low/medium/high）和 `reason`（1–160 个 Unicode 字符，去除首尾空白后不得为空）。这是主代理自报的决策摘要，不是插件计算的客观评分。理由会落盘和展示，只写简短的能力/风险/成本依据，不填任务原文、秘密、个人信息或推理过程。插件不能自动判断一段理由是否含有敏感信息。

## 记录与显示

- 派遣结果及其持久化 meta、历史记录、可见性 SSE 含可选 `selection` 和 `tokenUsage`。
- 派遣卡片展开详情及 Agent 管理的调用记录显示决策与用量；缺少字段的旧记录显示未记录/未知。
- 用量在子代理结束时，从官方 `Session.ownEvents()` 读取；不读取或累计继承的父会话记录。
- 只累计已提交 `assistant/message.data.usage`，按序号去重。`assistant/attempt` 记为未计量尝试，不从文本或流推估。
- `inputTokens`、`outputTokens`、`totalTokens`、`cacheReadTokens`、`cacheWriteTokens`、`reasoningTokens` 分别累计；未披露的可选计数保留 null，不把缓存/推理再加到总计，也不推算总计。
- `status=reported` 表示所有所见已提交回复均有可用 input/output 计数；`partial` 表示存在缺失回复、未计量尝试或安全整数溢出；没有可用回复用量为 `unknown`。这不是账单完整性保证。
- 失败/取消保留已有统计；统计故障不改变派遣成败。后台初始返回 tokenUsage=null，最终值以历史/可见性记录为准。
- 历史中的 completed 仅表示子代理回合完成，不表示转写准确或产品验收通过。仍由主代理核验质量。

## 验证与对照

自动测试覆盖：短提示长度、按需分级规则、可选参数兼容性、授权/锁定/强度拒绝、前后台记录、失败与取消、旧记录恢复、重复事件、未知/零值区分、父会话排除、UI 文本显示。

这些是契约与模拟回归，不是真实模型对照，也不能证明 Token 节省。Host 代码需重启后生效；本次不会主动重启桌面应用。

重启后的真实对照建议：
1. 固定简单检索、高风险审查、图像读取各一个公开或非敏感样本，保持任务、上下文和验收标准一致。
2. 图像样本先单代理读取一张，要求识别图中特有内容；链路失败就停止，不能批量派遣或提高强度伪装解决。
3. 比较现有默认与按需选择，记录实际路由、主代理与子代理总 Token、缓存计数、响应时间、验收结果和重做次数；注明缺失数据，不估算费用。
4. 样本不足不推出能力排名；只有总开销下降且质量不退步才声明节省。当前尚无本次新代码的真实对照数据。
